# Web Traffic Analytics Dashboard

## Project Overview
The Web Traffic Analytics Dashboard is a data analysis project designed to examine website traffic, user engagement, and conversion performance. It helps identify traffic sources, bounce rates, session durations, and user drop-off points.

## Objectives
- Analyze website traffic from Organic, Ads, Social, and Direct channels.
- Calculate bounce rate and average session duration.
- Measure pageviews and conversion rates.
- Identify potential drop-off points in the conversion funnel.
- Present insights through interactive charts and visualizations.

## Features
- Interactive dashboard with filters.
- Traffic channel performance comparison.
- Bounce rate and conversion rate analysis.
- Landing-page performance charts.
- Conversion funnel visualization.
- Downloadable PDF analytics report.

## Technologies Used
- HTML
- CSS
- JavaScript
- Data analysis and visualization

## Project Files
- `index.html` — Interactive analytics dashboard.
- `Web_Traffic_Analytics_Dashboard.pdf` — Analytics report.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the filters to explore the dashboard.
